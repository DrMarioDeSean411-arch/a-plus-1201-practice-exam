## What Is This?

A single self-contained HTML tool covering all five domains of the CompTIA A+ Core 1201 exam. It combines four modes in one file:

| Mode | Purpose |
|------|---------|
| **Practice Questions** | 250 original questions (50/domain), auto-graded, with rationale and an instructor misconception note on every question |
| **Domain Study Guide** | Expandable cards covering each domain's official sub-objectives in plain language |
| **Visual Reference** | 7 original inline SVG diagrams — no external images or hosted assets |
| **Interactive Foundations** | 5 hands-on mini-tools: subnet calculator, device anatomy, storage slider, cloud cost simulator, troubleshooting decision tree |

Everything runs entirely in the browser. Answers are session-only (no localStorage) and reset when the tab closes.

## How to Use This Tool

1. Open the **Practice Questions** mode and pick a domain.
2. Answer each multiple-choice question — the correct answer, rationale, and an instructor misconception note appear immediately.
3. Use the domain summary cards and the breakdown bars at the bottom to see where you're weakest.
4. Switch to **Domain Study Guide** to review the underlying concept before retrying a domain.
5. Use **Visual Reference** for a quick look at motherboard layout, port shapes, the OSI model, a SOHO topology, storage comparisons, iOS/Android structure, and hypervisor types.
6. Use **Interactive Foundations** to build intuition: calculate a real subnet, click through a phone's internals, drag a storage capacity slider, run a rough cloud-cost estimate, or walk a "device won't turn on" decision tree.
